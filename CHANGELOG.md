# Changelog

## [0.2.0] - 2026-08-21
## Added
- Keep alive option when controller not used with configurable (indefinitely) time-out

## Changed
- esp32 core refactored to be easier to import and run
- Improved re-connect behavior

## [0.1.1] - 2026-08-12

## Changed
- Inspector tool has separate columns for Not Set Up, Unpaired and Paired with scroll
- Inspector tool has a button per BLE device to Connect, Disconnect or Forget
- Inspector tool can switch between simultaneous connected devices to read them

## [0.1.0] - 2026-08-08

_First release._
