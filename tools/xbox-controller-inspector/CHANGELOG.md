# Changelog

All notable changes to `xbox-controller-inspector` are documented here.

## [0.2.0] - 2026-08-21

### Changed

- Switched the parser dependency to the restored standalone
  `xbox-controller-core` crate.
- Updated the package version alongside the workspace's ESP library release.

## [0.1.1] - 2026-08-12

### Added

- Added separate scrollable columns for connected, disconnected, and not-set-up
  controllers.
- Added per-device Connect, Disconnect, and Forget actions.
- Added switching between multiple connected controllers for input inspection.

## [0.1.0] - 2026-08-08

- Initial release of the Linux BLE controller inspector.
